# 评级五级量表

## 量表定义

| 评级 | 数值 | 方向 | 含义 |
|------|------|------|------|
| 买入 | 5 | 看多 | 强烈看好，建议建仓或加仓 |
| 增持 | 4 | 看多 | 偏多，建议持有或适度加仓 |
| 持有 | 3 | 中性 | 方向不明确，维持现有仓位 |
| 减持 | 2 | 看空 | 偏空，建议减仓或锁定利润 |
| 卖出 | 1 | 看空 | 强烈看空，建议清仓止损 |

## 评级档位变化（rating_shift）

`rating_shift = 当前评级数值 - 上次评级数值`

| shift 值 | 标签 |
|----------|------|
| +2 或以上 | 大幅调升 |
| +1 | 小幅调升 |
| 0 | 不变 |
| -1 | 小幅调降 |
| -2 或以下 | 大幅调降 |

## 方向映射

| 评级 | 方向 |
|------|------|
| 买入、增持 | 看多 |
| 持有 | 中性 |
| 减持、卖出 | 看空 |

## 方向一致性判断规则

根据同一标的历次分析的方向序列判断：

| 方向序列模式 | 一致性标签 |
|-------------|-----------|
| 全部看多 | 持续看多 |
| 全部看空 | 持续看空 |
| 全部中性 | 持续中性 |
| 看多 → 看空（中间无穿插） | 由多转空 |
| 看空 → 看多（中间无穿插） | 由空转多 |
| 含中性穿插但趋势明确 | 偏多/偏空（附注"中间有中性穿插"） |
| 看多看空交替出现 | 方向摇摆 |

## 预测正确性判断

- 前提：`verified = true` 且 `score` 不为 null
- 规则：`score > 50` 视为方向预测正确，`score <= 50` 视为方向预测错误
- `verified = false` 时不做判断（显示为"—"或"未验证"）
