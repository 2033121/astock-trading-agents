# A股行业对比解读

将"单股基本面报告"升级为**相对估值横截面**：不在真空里看 PE/PB，而是回答
"与同行业相比，这只股票处于贵、平还是便宜的分位"。

## 数据源

全部使用仓库自带工具（`agents/utils/industry_chain_tools.py` 与
`fundamental_data_tools.py`，经 `route_to_vendor` 多供应商容灾），**不引入新接口**：

| 工具 | 返回 | 用途 |
|------|------|------|
| `get_fundamentals(symbol)` | 总市值/流通市值/PE/PB/行业分类 | 目标本体指标 |
| `get_industry_peers(symbol)` | 同行业前 15 家成分股：股价/市值/PE/PB | 对比横截面 |
| `get_industry_chain(symbol)` | 产业链位置/上下游/竞争对手/份额 | 竞争格局定级 |

## 工作流

### W1：相对估值定位

1. 取目标股 `get_fundamentals` 指标（PE、PB、市值）与所属行业（若为多业务，逐板块处理，见 W2）。
2. 取 `get_industry_peers` 前 15 家，构建可比集（剔除目标自身、剔除 PE 为负/缺失的公司，标注剔除数）。
3. 计算可比集：**中位 PE、中位 PB、中位市值**；目标相对位置按分位数：目标 PE 排名 / 剔负后的样本数 → 分位 = 1 - (排名-1)/(n)，越低越便宜。
4. **输出结构**：
   ```json
   {
     "target": {"code": "600519", "pe": 18.5, "pb": 5.2, "market_cap": 18000},
     "industry_median": {"pe": 22.1, "pb": 3.4},
     "pe_percentile": 0.35,          // 稀释到 0-1，低=便宜
     "pb_percentile": 0.80,
     "sample_size": 14, "excluded": 1,
     "relative_valuation": "PE 相对行业偏便宜（分位 0.35），PB 相对偏贵（分位 0.80）",
     "caution": "PE 与 PB 分位背离时优先解释质量差异（ROE/增速），不要机械套 percentile 结论"
   }
   ```
5. **注入点**：结论摘要追加进 `fundamentals_report` 末尾（标注"行业对比 akshare/东方财富行业板块"），并将 `relative_valuation` 一句话进 PM 决策矩阵的关键数值。

### W2：多业务板块分别对比

`industry_chain` 返回多板块时（如某公司同时有 主业+第二曲线）：
- 每个板块各选 3-5 家可比公司（以业务描述/主营构成匹配，不机械用行业板块成分股）；
- 分别计算分位，最终按营收占比加权叙述，指出"哪个板块是核心估值锚"。

### W3：块效应提示（板块轮动轻量版）

不做独立轮动模型，只输出提示维度：
- 同板块近 5 日相对目标的表现差（若 peers 数据带股价则现算，缺则省略）；
- 目标在可比集中市值排名（>80% 分 位提示大盘股权重效应，涨跌跟随板块 β 高）；
- 何时升级为独立"板块轮动"分析：出现板块级净买额/龙虎榜信号（联动 `龙虎榜解读` 技能）。

## 解读纪律

1. **分位数不是估值结论**：PE 分位低可能是价值陷阱（周期顶/减值风险），必须与 `get_industry_chain` 的竞争格局、ROE 趋势互相印证后再给"偏贵/偏便宜"结论。
2. 剔负规则必须显式说明剔除数量；样本 <5 家时改用"全部列出人工对比"而不是统计分位。
3. 不同行业不横向比 PB（重资产 vs 轻资产无意义）；跨行业对比仅限同产业链上下游议价分析。
4. 工具返回失败时诚实输出"数据不足"，不得用训练记忆里的历史估值冒充当前行业分位。
