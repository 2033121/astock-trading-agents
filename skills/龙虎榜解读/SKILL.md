# A股龙虎榜解读

将龙虎榜公开数据转化为**可注入分析管线的资金信号摘要**。所有接口均基于 akshare，
列名以实测为准（akshare ≥1.14，2026-09 验证）。

## 数据源（已验证）

| 接口 | 参数 | 用途 |
|------|------|------|
| `ak.stock_lhb_detail_em(start_date, end_date)` | `YYYYMMDD` | 每日榜单总表（含代码/名称/涨跌幅/净买额/上榜原因/上榜后1·2·5·10日表现） |
| `ak.stock_lhb_stock_detail_em(symbol, date, flag)` | `flag="买入"/"卖出"`、`date=YYYYMMDD` | 个股买卖五席位明细（营业部名称/金额/占比/净额），**仅对上榜日有效，未上榜返回 None** |
| `ak.stock_lhb_jgstatistic_em(symbol)` | `"近一月"/"近三月"/"近六月"/"近一年"` | 机构席位行为统计（机构买入/卖出额与次数、净买额） |

实测列名：

- `stock_lhb_detail_em`：`代码, 名称, 上榜日, 解读, 收盘价, 涨跌幅, 龙虎榜净买额, 上榜原因, 上榜后1/2/5/10日, 换手率, 流通市值 …`
- `stock_lhb_stock_detail_em`：`交易营业部名称, 买入金额, 买入金额-占总成交比例, 卖出金额, 净额, 类型`

## 工作流

### W1：个股榜日解读（对分析管线注入用）

输入：股票代码 + 上榜日。

1. **拉取总表行**（`stock_lhb_detail_em` 过滤 `代码`），记录`上榜原因`（涨幅偏离/换手率异常/连续三日…）与`净买额`、`净买额占总成交比`。
2. **拉取买卖席位明细**（`stock_lhb_stock_detail_em`，买/卖各一次；未上榜则跳过并说明）。
3. **席位分类**：
   - `机构专用` → 机构席位
   - 名称含 `东方财富`（量化常用节点）＋高频小单 → 疑似量化/散户通道
   - 其余营业部 → 按累计净额排高者记为活跃游资席位
4. **生成信号摘要**（≤300 字，注入 news/sentiment 分析师上下文）：
   - 方向判定基线：机构净买 + 知名席位主买 → 偏看多；机构净卖或一日游游资对倒 → 偏谨慎
   - 强弱参考：`净买额占总成交比`（>5% 显著，<1% 噪音）
   - 结合深交所/上交所披露的连续上榜次数与上榜后历史表现字段
5. **输出结构**：`{股票, 日期, 上榜原因, 净买额, 席位结构=机构N/游资N, 信号结论, 依据}`

### W2：全市场热力扫描（自选股筛选）

`stock_lhb_detail_em` 取近 N 日 → 按 `净买额` 排序 → 列出机构净买TOP与净卖TOP →
供"同板块轮动对比"式分析使用。注意剔除一字板不可买标的（涨停但无卖一席位分歧时流动性风险高）。

## 解读纪律（重要）

- 龙虎榜是**事后披露**（交易日收盘后），不得当作盘中领先信号；结论一律以"资金行为佐证"而非"预测依据"的口吻表述。
- 席位归因是启发式："机构专用"实义明确，游资/量化的营业部识别要弱化断言（"疑似"）。
- 单日榜单噪音大：跨 ≥3 个交易日观察席位重叠情况再下结论。
- 数据缺失（未上榜/接口改版）时诚实声明，禁止编造席位名称或金额。

## 与分析管线的集成

- **news_analyst / sentiment_analyst 的注入点**：将 W1 输出摘要附加到其工具上下文（与 `eastmoney_news` 数据并列标注来源 `龙虎榜 akshare`）。
- **快照对比联动**：若该股有历史快照且当日上榜，在 `analysis_note` 字段记录上榜信号，供 `快照跟踪对比` 技能回溯验证龙虎榜信号的事后有效性。
