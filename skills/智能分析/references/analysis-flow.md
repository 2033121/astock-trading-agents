# A股智能分析 — 7阶段分析流水线架构

本文档描述 `astock-trader` 多Agent分析流水线的完整架构，帮助理解分析结果是如何产生的。

## 架构总览

```
用户输入(股票代码+日期)
        │
        ▼
┌─────────────────────────────────────┐
│  Stage 1: 数据采集                    │
│  (行情/技术指标/财报/新闻)             │
└───────────────┬─────────────────────┘
                │
                ▼
┌─────────────────────────────────────┐
│  Stage 2: 多分析师并行分析             │
│  技术面 │ 情绪 │ 新闻 │ 基本面        │
└───────────────┬─────────────────────┘
                │
                ▼
┌─────────────────────────────────────┐
│  Stage 3: 多空辩论                    │
│  看多研究员 ←→ 看空研究员              │
│  (交替辩论 N 轮)                      │
└───────────────┬─────────────────────┘
                │
                ▼
┌─────────────────────────────────────┐
│  Stage 4: 研究经理综合                │
│  → 投资计划                          │
└───────────────┬─────────────────────┘
                │
                ▼
┌─────────────────────────────────────┐
│  Stage 5: 交易员生成交易提案           │
└───────────────┬─────────────────────┘
                │
                ▼
┌─────────────────────────────────────┐
│  Stage 6: 三方风控辩论                │
│  激进 ←→ 保守 ←→ 中性                │
│  (循环辩论 M 轮)                      │
└───────────────┬─────────────────────┘
                │
                ▼
┌─────────────────────────────────────┐
│  Stage 7: 组合经理最终决策             │
│  → 评级 (买入/增持/持有/减持/卖出)     │
└─────────────────────────────────────┘
```

---

## Stage 1: 数据采集

**目标**：收集分析所需的全部原始数据。

**数据源**：
- **行情数据**（akshare）：当前价格、涨跌幅、成交量、换手率
- **技术指标**（akshare）：MA、MACD、KDJ、RSI、BOLL 等
- **财务报表**（akshare）：营收、净利润、PE/PB/ROE 等核心指标
- **新闻资讯**（东方财富）：近期公告、行业新闻、政策动态

**输出**：结构化的原始数据包，供后续阶段使用。

---

## Stage 2: 多分析师并行分析

**目标**：4类专业分析师**同时**对数据包进行独立分析，各自产出专业报告。

### 2.1 技术面分析师（Market Analyst）

- 分析K线形态（阳包阴、十字星、头肩顶等）
- 计算和解读技术指标（MA交叉、MACD背离、KDJ超买超卖等）
- 量价关系分析（放量突破、缩量回调等）
- 支撑位和压力位判断
- **输出**：`market_report` — 技术面分析报告

### 2.2 情绪分析师（Social/Sentiment Analyst）

- 市场情绪指标（恐惧/贪婪指数）
- 资金流向分析（主力资金、北向资金）
- 投资者行为特征（散户/机构博弈）
- 融资融券数据
- **输出**：`sentiment_report` — 市场情绪分析报告

### 2.3 新闻舆情分析师（News Analyst）

- 近期重大新闻事件梳理
- 政策面影响评估
- 行业竞争格局变化
- 公司公告解读
- **输出**：`news_report` — 新闻舆情分析报告

### 2.4 基本面分析师（Fundamentals Analyst）

- 财务报表三表分析（利润表、资产负债表、现金流量表）
- 盈利能力指标（毛利率、净利率、ROE）
- 成长性指标（营收增速、净利润增速）
- 估值水平（PE、PB、PS，与行业对比）
- **输出**：`fundamentals_report` — 基本面分析报告

---

## Stage 3: 多空辩论

**目标**：通过辩论机制让对立观点充分碰撞，避免单一分析师的偏见。

**参与者**：
- **看多研究员（Bull Researcher）**：基于分析报告寻找买入理由
- **看空研究员（Bear Researcher）**：基于分析报告寻找风险和问题

**辩论机制**：
- 交替发言，每轮各自提出论点和反驳
- 默认进行 **1 轮**辩论（可通过 `--debate-rounds` 参数调整）
- 每轮辩论后，双方都能看到对方的最新论点并做出回应
- 辩论轮数越多，分析越深入，但耗时也更长

**输出**：`investment_debate_state` — 包含完整辩论记录和双方最终立场。

---

## Stage 4: 研究经理综合

**目标**：研究经理（Research Manager）作为中立方，综合多空双方观点，形成平衡的投资方案。

**职责**：
- 评估看多论点的合理性和证据强度
- 评估看空论点的合理性和证据强度
- 权衡风险和收益
- 制定初步投资计划（方向、仓位、时间框架）

**输出**：`judge_decision` — 研究经理的综合投资计划。

---

## Stage 5: 交易员生成交易提案

**目标**：交易员（Trader）基于研究经理的投资计划，生成具体可执行的交易方案。

**内容包括**：
- 具体操作建议（买入/卖出/持有）
- 建议价位区间
- 仓位比例建议
- 止盈止损设置
- 执行时间建议

**输出**：`trader_investment_plan` — 交易员的具体交易提案。

---

## Stage 6: 三方风控辩论

**目标**：从不同风险偏好角度对交易提案进行充分讨论，确保风险被全面评估。

**参与者**：
- **激进风控（Aggressive Risk Manager）**：倾向于接受更高风险换取更高收益
- **保守风控（Conservative Risk Manager）**：倾向于控制风险，宁可错过机会
- **中性风控（Neutral Risk Manager）**：平衡风险和收益

**辩论机制**：
- 三方循环讨论，每轮各自发表观点并回应他人
- 默认进行 **1 轮**讨论（可通过 `--risk-rounds` 参数调整）
- 讨论焦点：当前交易方案的风险收益比是否合理

**输出**：`risk_debate_state` — 包含完整风控讨论记录和综合风控评估。

---

## Stage 7: 组合经理最终决策

**目标**：组合经理（Portfolio Manager）作为最终决策者，综合所有信息给出投资评级。

**决策输入**：
- 4份分析师报告（Stage 2）
- 多空辩论记录和研究经理方案（Stage 3-4）
- 交易员提案（Stage 5）
- 风控辩论结果（Stage 6）

**输出评级**（五级制）：

| 评级 | 英文 | 含义 |
|------|------|------|
| 买入 | Strong Buy | 多重利好共振，风险可控，建议积极建仓 |
| 增持 | Buy | 基本面良好，估值合理，建议逐步加仓 |
| 持有 | Hold | 多空因素均衡，维持当前仓位观望 |
| 减持 | Sell | 风险因素增多，建议逐步减仓锁定利润 |
| 卖出 | Strong Sell | 多重利空叠加，风险不可控，建议清仓离场 |

**输出**：`final_trade_decision` — 包含评级、理由、操作建议和风险提示的完整决策。

---

## 记忆与反思系统

分析完成后，结果会自动记录到**决策记忆日志**中：
- 记录本次分析的评级和决策要点
- 状态标记为 `pending`（待结算）
- 用户可在后续使用「决策记忆」技能查看、结算或清理历史记录
- 结算时会计算实际收益率，并生成反思总结，用于改进未来分析质量

## 技术实现

- **框架**：基于 [LangGraph](https://github.com/langchain-ai/langgraph) 构建的有向图状态机
- **Agent 数量**：共 14 个 AI Agent 协作（4 分析师 + 2 多空研究员 + 1 研究经理 + 1 交易员 + 3 风控 + 1 组合经理 + 数据采集Agent + 工具Agent）
- **模型配置**：支持深度思考模型（用于辩论和决策）和快速模型（用于数据采集和格式化）分离
- **数据源**：默认使用 akshare（行情/技术/财务）+ 东方财富（新闻）
- **检查点**：可选 SQLite 检查点，支持中断恢复
