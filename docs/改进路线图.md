# 改进路线图（Roadmap）

> 更新：2026-09-11。承接 `docs/Token控制改进方案.md` 的调研结论，将全项目可改进方向收敛为一份可执行清单。
> 每条给出目标、优先级与验收方式；已完成的条目在 CHANGELOG 中留痕。

## P0 — 性能与成本

| # | 方向 | 现状 | 行动 | 验收 |
|---|------|------|------|------|
| 1 | 统一系统提示词前缀（Token 策略 2B） | ✅ 已完成（68f7d0f） | — | guard tests 通过 |
| 2 | 分层模型路由（Token 策略 1） | 已有四层模型但未按任务路由 | 在 `default_config` 增加 `TASK_COMPLEXITY_MAP`：极简任务→规则引擎（0 Token），摘要/提取→quick，辩手→heavy，经理→deep | 单测覆盖映射正确性 |
| 3 | 摘要式上下文传递（Token 策略 2A） | 研究员/基金经理拿到 4 份完整报告 | 在 `context_slimmer.py` 增加 `summarize_report()`，仅传递结论+关键数值+风险≤3条+置信度 | 管线下游输出质量不回归（抽样复盘） |
| 4 | 语义缓存（Token 策略 3） | 无 | `llm_clients/semantic_cache.py`，同股 1 小时内相似查询返回缓存，阈值 0.92 | 命中率日志 + 复现实验 |

## P1 — 能力边界

| # | 方向 | 说明 |
|---|------|------|
| 5 | **MCP server 化** | 提供 `astock analyze <code>` / 快照查询 / 回测复盘三个工具的 stdio MCP server，使任意 agent host 可直接调用，扩大项目受众 |
| 6 | **外部校准接入** | 跟踪可公开结算、与 A 股个股评级可比的第三方记分板（已知候选：Headline Arena，见 issue #1；当前其赛道为宏观期货/Civic Index，题域错位暂不接入）。接入原则：只镜像最终评级与置信度，不镜像内部记忆 |

| 8 | 数据源容灾 | akshare 失败时自动降级 tushare/mx（已有实现雏形，需加降级顺序测试） |
